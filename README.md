## Power BI Data Analytics Project

A data analytics and visualization project built using **Microsoft Power BI** to transform raw data into meaningful insights through interactive dashboards and reports.

### Key Features

* Data cleaning and transformation using Power Query
* Interactive dashboards and visualizations
* KPI cards and performance metrics
* Filters and slicers for dynamic analysis
* Data modeling and relationships
* DAX measures and calculated columns
* Business insights and data-driven reporting

### Technologies Used

* **Microsoft Power BI**
* **Power Query**
* **DAX**

This project demonstrates practical skills in **data analysis, visualization, dashboard development, and business intelligence**.
